# mongoDB-insta-analytics
This project tries to analyze Instagram user behavior using MongoDB and identify relationships between usage intensity, mental wellbeing, lifestyle habits, demographics, influencer potential, and physical health across 5,000+ user records from 10 countries spanning 2010-2025.


Dashboard Link : https://charts.mongodb.com/charts-project-0-opjspsp/public/dashboards/38727f2c-aa49-43f5-8c0d-34f93094dccb
(sometimes the link might not work because the MongoDB cluster gets auto-paused)
